# Support

This theme is community-maintained open-source software. It is not an official
product of the Lehrstuhl für Mustererkennung, and the chair does not support it.

Before opening an issue:

1. Read the [README](README.md), in particular § Font choice and
   § Quarkdown-specific gotchas — most layout surprises are one of those.
2. Confirm the problem on the version in `theme.json` with a supported Quarkdown
   release (see the compatibility matrix in the README).
3. Reduce it to a minimal `.qd` file. `example/main.qd` is a good starting point.
4. Check whether the LaTeX reference (`lmedoc.cls`) behaves the same way. If the
   theme deviates, say so — that is usually the actual bug report.

Use the bug-report template for reproducible defects and the feature-request
template for scoped proposals. Include the theme version, Quarkdown version,
operating system, installed fonts, the exact build command, and the observed
output.

Do not attach an unpublished thesis, personal data, or institution assets that
are not already in this repository. A synthetic reproduction is always enough.

There is no guaranteed response time and no private consulting support.
